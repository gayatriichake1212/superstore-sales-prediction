# 🛒 Superstore Sales Prediction (Outlet Sales Predictor)

A machine learning project that predicts the **sales of a product at a retail outlet** using product details and outlet characteristics. A **K-Nearest Neighbors (KNN) regression** model is trained in a Jupyter notebook and served through a **Flask** web app with a simple form-based interface.

---

## 📌 Overview

| Item | Details |
|------|---------|
| **Problem type** | Regression (predict `Item_Outlet_Sales`) |
| **Algorithm** | K-Nearest Neighbors Regressor (scikit-learn) |
| **Dataset** | Outlet sales data, 8,523 records, 12 columns |
| **Target variable** | `Item_Outlet_Sales` |
| **Front end** | Flask web app (`app.py`) with HTML/CSS |

## 📊 Dataset

| Column | Description |
|--------|-------------|
| `Item_Identifier` | Unique product ID (dropped before training) |
| `Item_Weight` | Weight of the product |
| `Item_Fat_Content` | Low Fat / Regular |
| `Item_Visibility` | Share of display area allotted to the product in the store |
| `Item_Type` | Product category (16 categories) |
| `Item_MRP` | Maximum retail price of the product |
| `Outlet_Identifier` | Unique store ID (10 outlets) |
| `Outlet_Establishment_Year` | Year the outlet was established |
| `Outlet_Size` | Small / Medium / High |
| `Outlet_Location_Type` | Tier 1 / Tier 2 / Tier 3 |
| `Outlet_Type` | Grocery Store or Supermarket Type 1/2/3 |
| `Item_Outlet_Sales` | **Target:** sales of the product at the outlet |

## ⚙️ How It Works

### 1. Data Preprocessing (in the notebook)

| Step | Treatment |
|------|-----------|
| Missing `Item_Weight` (1,463 rows) | Filled with the median (12.6) |
| Missing `Outlet_Size` (2,410 rows) | Filled with the mode (Medium) |
| `Item_Fat_Content` | Inconsistent labels (`LF`, `low fat`, `reg`) cleaned and mapped to 0 = Low Fat, 1 = Regular |
| `Outlet_Size` | Ordinal encoding: Small = 0, Medium = 1, High = 2 |
| `Outlet_Location_Type` | Ordinal encoding: Tier 1 = 0, Tier 2 = 1, Tier 3 = 2 |
| `Item_Type`, `Outlet_Type` | One-hot encoding (`drop_first=True`) |
| `Outlet_Identifier` | One-hot encoding (all 10 outlets kept) |
| `Item_Identifier` | Dropped |

The final feature set has **35 columns**.

### 2. Model Training and Tuning
- Baseline: `KNeighborsRegressor()` on MinMax-scaled data.
- Hyperparameter tuning with **GridSearchCV** and **RandomizedSearchCV** over `n_neighbors` and `p` (distance metric).
- The final model saved to `knn_regression_model.pkl` is `KNeighborsRegressor(n_neighbors=7, p=1)`, trained on the unscaled features with an 80/20 split (`random_state=42`).

### 3. Web App (`app.py`)
- Loads the saved model on startup.
- The form at `/` collects product and outlet details.
- `/predict` builds the one-hot encoded input row, aligns the columns to the model's training order and returns the predicted sales on the same page.

---

## 📈 Model Performance (R² on the test set)

| Model | R² Score |
|-------|----------|
| KNN baseline (scaled data, default settings) | ~0.498 |
| KNN tuned with GridSearchCV (k = 7, p = 2, scaled data) | ~0.505 |
| **Final saved model** (k = 7, p = 1, unscaled data, 80/20 split) | **~0.550** |

For the scaled baseline split, RMSE was about 1,188 and MAE about 838.

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- pip

### Installation

```bash
# 1. Go to the project folder
cd Super_store

# 2. (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install flask pandas scikit-learn numpy
# For the notebook only:
pip install jupyter matplotlib seaborn
```

### Run the app

```bash
python app.py
```

Open **http://127.0.0.1:5000** in your browser.

> `app.py`, `knn_regression_model.pkl`, `templates/` and `static/` must stay in the same folder structure shown above.

### Retrain the model (optional)

Open `KNN Regression.ipynb` in Jupyter and run all cells. The last cells save a new `knn_regression_model.pkl`.

## 🖥️ Using the App

1. Enter the item details: weight, fat content, visibility, MRP and item type.
2. Enter the outlet details: identifier, size, location tier, type and establishment year.
3. Submit the form to see the **Predicted Outlet Sales**.

## 🔧 Future Improvements

- **Scale the features inside the model.** KNN is distance-based, so unscaled features such as `Item_MRP` and `Outlet_Establishment_Year` dominate the result. Use a `Pipeline` with `MinMaxScaler` or `StandardScaler` so scaling is applied automatically in the app too.
- Try tree-based models such as Random Forest or Gradient Boosting, which usually perform better on this type of data.
- Engineer features such as outlet age (current year minus establishment year) and price per unit weight.
- Use cross-validation for the final evaluation and report MAE and RMSE for the final model.
- Add `requirements.txt` with pinned versions and input validation in the app.

---

## ⚠️ Limitations

- An R² of about 0.55 means the model explains only about half of the variation in sales, so predictions are rough estimates.
- The model was trained on unscaled data, so distance calculations are dominated by a few large-valued features.
- The web form has no option for the outlet `OUT010`, and the `Baking Goods` item type is not listed either (it is the baseline category in the encoding, so it would be represented by all zeros).
- The model is saved with `pickle`. Use the same scikit-learn version for training and running the app (the included model was saved with 1.7.2), and only load pickle files you trust.
- The Flask app runs with `debug=True`, which is for development only.
